# Breast Cancer Detection – End-to-End ML Project

Predict malignant (1) vs benign (0) tumors using the Breast Cancer Wisconsin (Diagnostic) dataset.

## Project Structure
- `breast+cancer+wisconsin+diagnostic/` – Dataset files (`wdbc.data`, `wdbc.names`)
- `notebooks/breast_cancer_detection.ipynb` – E2E notebook (EDA, preprocessing, models, eval, SHAP, save best model)
- `models/` – Best model (`*.joblib`) generated by the notebook
- `reports/figures/` – Intermediate plot outputs (auto-generated)
- `visualizations/` – Final PNG plots to commit to GitHub
- `scripts/export_basic_plots.py` – Quick plot exporter (fallback)

## Setup
```bash
# From project root
python -m venv .venv
# Windows PowerShell
. .venv/Scripts/Activate.ps1
pip install -r requirements.txt
```

## Run
1) Launch Jupyter and open the notebook:
```bash
jupyter notebook notebooks/breast_cancer_detection.ipynb
```
2) Run all cells top-to-bottom to:
- Load data, EDA, preprocessing
- Train Logistic Regression, Random Forest, SVM (and optionally XGBoost)
- Evaluate with Accuracy, Precision, Recall, F1, ROC-AUC
- Generate and save plots to `reports/figures`
- Save the best model to `models/`

3) Export PNG plots for GitHub:
```bash
python scripts/export_basic_plots.py
# Then copy PNGs (already handled by our workflow) into `visualizations/`
```
The `visualizations/` folder now contains the PNG files to commit.

## Notes
- SHAP plots are generated if `shap` is available (optional).
- If the local UCI CSV is missing, the notebook falls back to `sklearn.datasets.load_breast_cancer` and aligns feature names.

## Commit to GitHub
Recommended to commit:
- `README.md`, `requirements.txt`
- `notebooks/breast_cancer_detection.ipynb`
- `visualizations/` (PNG images)
- `scripts/export_basic_plots.py`

By default, `.gitignore` excludes heavy/ephemeral artifacts (e.g., `models/`, `reports/`, `.venv/`).
